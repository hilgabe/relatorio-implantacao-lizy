# 10 — Glossário inicial

| Termo | Definição nesta documentação | Fonte/estado |
|---|---|---|
| OS | Ordem de serviço aberta por equipamento recebido | V01 — Confirmado |
| Estoque de Terceiro | Controle de equipamentos pertencentes a clientes, desde recebimento até devolução | V01 — Confirmado |
| Ficha | Conjunto de campos e checklists específico do tipo de equipamento | V01 — Confirmado |
| Peritagem | Etapa técnica chamada de “Análise” em algumas configurações; termo usado para a Elétrica Visão | V01 — Confirmado |
| Laudo técnico | Documento gerado a partir da peritagem, inclusive de forma parcial | V01 — Confirmado |
| Laudo final | Documento gerado após concluir a execução/PCP | V01 — Confirmado |
| Proposta comercial | PDF do orçamento com condições e apresentação configurável de peças/valores | V01 — Confirmado |
| Aguardando envio | Estado do orçamento antes de registrar/enviar a proposta | V01 — Confirmado |
| Aguardando aprovação | Estado depois do envio e antes da decisão do cliente | V01 — Confirmado |
| Requisição de estoque | Solicitação de materiais gerada após aprovação do orçamento | V01 — Confirmado |
| Requisição de compra | Solicitação gerada quando o material necessário não está disponível | V01 — Confirmado |
| PCP | Planejamento e Controle da Produção/serviços; planeja etapas e acompanha execução | V01 — Confirmado |
| Setor independente | Etapa aplicável apenas a alguns equipamentos/serviços e que precisa ser planejada | V01 — Confirmado |
| Setor obrigatório | Etapa sequencial automática após determinado ponto do fluxo | V01 — Confirmado |
| Apontamento | Registro de início/fim de atividade e técnico responsável | V01 — Confirmado |
| CIF/FOB | Modalidades de responsabilidade pelo frete; a regra interna ainda precisa ser definida | V01 — Pendente quanto à aplicação |
| MCP | Protocolo para expor ferramentas e dados a agentes de forma controlada; não é uma integração existente por si só | Avaliação técnica |
| API | Interface programática suportada pelo fornecedor; existência pública no ERP ainda não confirmada | Pendente |
| Webhook | Notificação enviada por sistema quando ocorre um evento | Não confirmado no Lizy |
| Homologação | Ambiente/processo de teste e aceite antes da produção | Uso recomendado; ambiente do Lizy pendente |
| DataFlow | Produto público da Lizy voltado a centralização, transformação e visualização de dados | W03 — Confirmado institucionalmente |
